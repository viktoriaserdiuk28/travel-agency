# Travel Agency :earth_americas:

## Project description

An interactive web application for exploring travel destinations, browsing accommodation options, and sharing experiences.

## Project Status

Work in Progress

## Features

- Explore available tours and hotels.
- View detailed information about each tour and hotel.
- Create and remove tours and hotel listings.
- Submit reviews through a form.
- Read customer reviews on the homepage.
- View reviews on individual tour and hotel pages.

## Technologies

- JavaScript
- React
- Node.js
- Express.js
- PostgreSQL
- HTML5
- CSS3

## Installation

1. Clone the repository:
   `git clone https://github.com/viktoriaserdiuk28/travel-agency.git`

2. Navigate to the project directory:
   `cd travel-agency`

3. Install dependencies:

- Backend:
  - `cd server`
  - `npm install`
- Frontend:
  - `cd ../client`
  - `npm install`

4. Create a `.env` file in the server directory using `.env.example` as a template and enter the required database settings.

5. Start the project in separate terminals:

- Backend:
  - `cd travel-agency/server`
  - `npm run dev`
- Frontend:
  - `cd travel-agency/client`
  - `npm run dev`
